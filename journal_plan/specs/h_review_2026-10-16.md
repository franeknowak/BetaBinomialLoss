# Module h — apply the 2026-10-16 plan review to the code

Source: 05_plan amendments 2026-10-16 #1–#3 and the rewritten §5. Tests: the suites of modules d, e, f, g (98 pass, 1 CUDA test skipped on the Mac).

## Changes
1. **No margins** (`b2j/stats.py`). `margin()` and `CAPS` removed. `verdict(result, kind, direction)`:
   - `superiority` (direction = predicted sign) → success / fail / inconclusive;
   - `difference` (direction = the sign meaning "first model better": +1 for BACC/mAP/AP, −1 for NLL/FCR) → "better" / "worse" / "no evidence of a difference".
   Equivalence and non-inferiority raise `ValueError`.
   `two_level_bootstrap` keeps its random draws and its scalar results bit for bit. It now also accepts array-valued metrics and returns a pointwise CI (needed for F5).
2. **S\*(m) dropped** (`b2j/posthoc.py`): `fit_s_of_m`, `s_of_m` and `pmaj_monotone` removed. `b2j/analysis.py`: no `:S*(m)` rows. The plug-in rows stay (step 1 of the ladder plug-in → Global-S → B²-r).
3. **F2** (`fig2_advantage_vs_n`): advantage = NLL(soft BCE + Global-S) − NLL(B²-r) at checkpoint B, per training-rater count n. The bootstrap shares the test clusters (CIFAR-10H within class) and resamples seeds separately per model, because the runs are different. The numbers are written to JSON.
4. **F5** (`fig5_pr_and_risk`): precision–recall curves of B²-r ranked by P_maj and by m, with soft BCE's m as a faint curve; the difference P_maj − m with its bootstrap band (paired seeds); risk–coverage. New helper `metrics.precision_at_recalls` (same rule as `fcr_at_recall`, which now calls it). Validation only; test opens only with `--open-test` (R3).
5. **Pilot** (`b2j/pilot.py`): the `margins` command and the S\*(m_B²) record removed; `choose` and the `pilot` block unchanged. Docstrings of `blocks.py` and `variants.py` updated.

## Not changed
- Training, run specs, the tuning choice, and the results on the cluster. `results/journal/pilot/margins.md` is historical and is not regenerated.
- The H5 Global-S comparator for the re-head and frozen part-B runs (open question for the user, amendment #5a): F2 handles frozen runs on all training rows only.
